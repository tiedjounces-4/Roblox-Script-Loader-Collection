## FAQ

### What is XCutors?

XCutors is a curated collection of popular Roblox script executors for Windows. It bundles multiple executor backends (Volt, Synapse Z, Potassium, Wave) under a single universal loader, making it easy to switch between them and manage your Lua scripts.

### Is XCutors free to use?

XCutors itself is a free open-source loader and script management interface. However, some individual executor backends included in the collection may require their own license or subscription from their respective developers.

### Which Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit). Older versions of Windows are not officially supported due to dependencies on modern system libraries.

### Why does my anticomponent flag XCutors?

Script executors inject code into other processes, which is behavior that heuristic anticomponent engines commonly flag. This is a false positive. You should add the XCutors installation folder to your anticomponent exclusion list. Always download XCutors from the official GitHub Releases page.

### How do I switch between executors?

Open the xcutorsLoader interface and use the executor dropdown selector to choose between Volt, Synapse Z, Potassium, or Wave. Click 'Attach' to initialize the selected backend. You can switch executors at any time without restarting the loader.

### Can I add my own scripts to the script hub?

Yes. Place your .lua or .txt script files into the 'Scripts' folder within your XCutors installation directory. They will automatically appear in the script hub sidebar. You can also load scripts via the File menu or paste them directly into the editor.

### The executor isn't attaching to Roblox. What should I do?

First, ensure you are running xcutorsLoader.exe as Administrator. Make sure Roblox is open and you are in a game. If the issue persists, try switching to a different executor backend, restarting Roblox, or temporarily disabling your anticomponent. Check the output console for specific error messages.

### Do I need to update the executors manually?

XCutors includes an auto-update feature that checks for new versions of each bundled executor backend when the loader starts. You can also manually trigger an update check from the Settings menu. If an update fails, you can re-download the latest XCutors release from GitHub.

### Is there a Discord or community for support?

Yes, check the repository README for a link to the official XCutors Discord server where you can get support, share scripts, request features, and stay updated on new releases.
